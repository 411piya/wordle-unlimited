# wordle-unlimited
A python based game similar to Wordle with unlimited guesses and hints. 
Includes - unlimited attempts, every 5 attempts there is a hint that tells you the letter at a certain index value,
input validation(makes sure it's 5 letters long and a string), if a letter is in the right place, it will show _ _ _ x _ 
for any all letters that is correct in the guess, tells you if a letter is in the wrong place but still in the word
How to play - Run the program, in the input area, put in your guess, it will print the letters that are correct. If none are correct 
it will just say try again. Keep guessing until it tells you that you win
About this Project - I built this project by myself as a first big project. 
Future improvements - Will add a screen interface with buttons and a background, will use a color system to represent letters instead of dashes,
have only one print to show the correct letters
